Non-Human Identity Management and Protection

A lightweight, low-cost framework for discovering, scoring, and monitoring
machine identities (API keys, service accounts, IoT credentials) — built for
CYBERSECURITY LAB II 

Overview

Non-Human Identities (NHIs) now outnumber human users in most organizations,
but they're often under-monitored and over-permissioned. This project builds
a simplified version of commercial NHI management tools, aimed at being
affordable and understandable for small businesses and students.

Aim

To design and implement a comprehensive Non-Human Identity Management
framework that secures machine identities.

Objectives

- Design a centralized Non-Human Identity Management Framework
- Implement automated discovery of machine identities across the environment
- Enforce least privilege access policies for all Non-Human Identities
- Build real-time monitoring and anomaly detection for NHI behaviour

Core Features

1. Discovery Engine— scans and lists machine identities (name, owner)
2. Risk Scoring Module— scores each identity 0–100 based on permissions, age, and activity
3. Risk Classification— labels identities Low / Medium / High / Critical
4. Automated Alerts— flags Critical (and High) risk identities
